# Junaid's live AI products (built solo)

## Nayld — AI voice-interview platform (nayld.ai, hire.nayld.ai)
Two-sided AI interview platform, built solo, live with real users. Candidates run mock interviews against realtime LLM voice agents at nayld.ai; employers use hire.nayld.ai to screen, invite, and run tier-2 interviews with full anti-cheat recording. Built end to end in ~6 weeks (a build his old agency would've needed 8–10 months and a full team for).
What he built: realtime voice agents on the OpenAI Realtime API over in-browser WebRTC (distinct personas/voices/prompts/models per interview tier); an async screening pipeline (S3 upload → Python Lambda extraction → SQS → Node.js scoring worker → structured fit scores/strengths into a Supabase schema); an interview-integrity system (camera + screen recording, mixed candidate/agent audio, client-side behavioral signals, deterministic 0–100 integrity score with timeline markers); layered billing (subscriptions → agent-scoped credits → legacy free credits); database-owned authorization; pnpm/Turbo monorepo on Terraform-managed Amplify + Lambda + S3 + SQS. Metrics: 257 users, 330+ interviews, 280+ resumes parsed; reached #2 product of the day on TinyHub at launch.
Stack: Next.js 14/16, React 18/19, TypeScript, Supabase (Postgres), OpenAI Realtime API + GPT-4o, AWS Lambda/SQS/S3/SES/Amplify, Terraform, Fastify.

## ClinicSynch — multi-tenant healthcare SaaS (clinicsynch.com)
Clinic operations stack: get clinics online in a day, public booking link, patient records, WhatsApp follow-ups. Built solo in ~4 weeks (vs ~4–6 months the old way). Live, onboarding clinics (9 onboarded).
What he built: a 3-app Next.js 14 monorepo (clinic dashboard + public mini-sites, cross-clinic patient portal, internal admin) with shared firebase/ui/messaging packages; tenant isolation enforced at the Firestore level (every read/write scoped by clinicId via security rules); an autonomous SEO agent ("Pulse") — orchestrator + ephemeral specialist sub-agents doing per-clinic keyword research, on-page optimization, content generation, and Search Console monitoring within hard per-clinic budgets, with a constraint engine, quality/uniqueness gate, versioned action ledger, and global kill-switch; public booking with server-side slot locking + double-book prevention; subscription tiers + paywall; a consultation workspace (vitals, notes, diagnoses, meds, lab orders, autosave, printable summary); WhatsApp Cloud API automation (reminders, follow-ups, two-way messaging, per-clinic audit logs); PWA with offline fallback.
Stack: Next.js 14, TypeScript, Firebase (Auth, Firestore, Cloud Functions, Storage, App Hosting), Tailwind, WhatsApp Business API, Playwright E2E.

## PSX Intelligence — AI financial analytics (psxintelligence.com)
"Bloomberg-lite" market-intelligence platform for the Pakistan Stock Exchange: realtime data, AI signals, technical analytics, risk tools. Built solo in ~40–50 days (vs ~6–8 months the old way), in phases. Live with 127 users.
What he built: a 5-minute ingestion pipeline (AWS Lambda containers on cron, Playwright scraping of the PSX site, PDF announcement extraction with pdfplumber + PyPDF2 fallback, structured JSON, retry/error handling) ingesting all 520 PSX tickers + hundreds of filings; cache invalidation via SSE (Lambda → API → Server-Sent Events → targeted TanStack Query invalidations); materialized views for research-heavy aggregations; AI signals + RAG (pgvector embeddings of company announcements + OpenAI analysis on price/fundamentals); tiered cache strategy; robust handling of delisted instruments, duplicate ticks, and noisy real-world feeds.
Stack: Next.js 15, TypeScript, Supabase (Postgres + pgvector), tRPC, TanStack Query, AWS Lambda (Python + Node), Playwright, OpenAI API, Recharts, shadcn/ui.
